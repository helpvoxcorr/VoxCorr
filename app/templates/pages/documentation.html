Introduction

VoxCorr est une application de correction audio de copies d'élèves. L'enseignant dicte sa correction oralement, l'IA (Mistral) la transcrit et structure automatiquement le retour écrit. Un QR code est généré pour chaque élève, donnant accès à sa correction sans compte requis.

Démarrage rapide : Créez une classe → ajoutez vos élèves → créez un devoir → enregistrez les corrections → publiez et partagez les QR codes.

Créer une classe

Depuis le tableau de bord, cliquez sur Nouvelle classe. Renseignez le nom de la classe, la discipline et l'année scolaire.

  1. Cliquer sur Nouvelle classe dans le tableau de bord.
  2. Renseigner le nom (ex : 3ème B), la discipline (ex : SVT) et l'année.
  3. Valider. La classe apparaît dans la section correspondant à sa discipline.

Ajouter des élèves

Dans la page de la classe, utilisez le formulaire en bas de la liste pour ajouter un élève. Le prénom et le nom réel sont chiffrés (AES-256) en base de données. Un alias mnémotechnique est généré automatiquement (ex : Renard-07).

Le vrai nom n'est jamais affiché publiquement. Seul l'enseignant connecté peut le déchiffrer.

Créer un devoir

Dans la page d'une classe, cliquez sur Nouveau devoir. Renseignez le titre, la date, le total de points, et ajoutez autant de questions que nécessaire avec leur barème.

Définissez bien vos questions avant de commencer les corrections — Mistral s'appuie sur leurs libellés pour extraire les notes automatiquement.

Enregistrer une correction

Sur la page du devoir, cliquez sur Corriger en face d'un élève.

  1. Cliquer sur le bouton micro vert pour démarrer l'enregistrement.
  2. Dicter la correction en mentionnant explicitement les notes : « Question 1, trois virgule cinq sur cinq… »
  3. Cliquer sur le bouton stop rouge.
  4. Cliquer sur Sauvegarder et analyser. Mistral génère la synthèse et extrait les notes.
  5. Vérifier les notes, ajuster si besoin, puis Publier et générer QR.

QR Code & page élève

Après publication, un QR code unique est généré. L'élève scanne ce QR avec son téléphone et accède à sa correction — sans compte, sans application.

Consultation hors-ligne

La page de correction se met en cache automatiquement. L'élève peut la relire sans connexion internet via le bouton Télécharger pour écoute hors-ligne.

Imprimer les corrections

Sur la page du devoir, cliquez sur Imprimer corrections. Une page s'ouvre avec un cadre par élève. Faites Ctrl+P ou cliquez Imprimer / Exporter PDF.

Anonymisation RGPD

Les noms et prénoms des élèves sont chiffrés en base de données (algorithme Fernet, AES-128). Seul l'enseignant connecté peut les déchiffrer. Les logs de consultation stockent l'adresse IP sous forme de hash SHA-256 irréversible.
